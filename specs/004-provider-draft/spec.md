# SPEC-004 — LLM 공급자 선택, 간편 지원서 생성, 독립 AI 검토

- 상태: Draft / M0~M1(Provider 기반), M4(생성·독립 리뷰) / 최초 통합 프로토타입 필수
- URS: UR-009, UR-010, UR-012; NFR-003, NFR-006, NFR-009

## 기능 요구사항
- **FR-004-01** 사용자가 본인 계정/키를 설정하고 지원 공급자 및 모델을 선택할 수 있다. M0에서 Mock 계약, M1에서 최초 실제 Provider 연결을 마련해 JD 분석·평가·생성·검토가 공유한다. 첫 공급자/모델은 실제 연결 구현 전 정하고 이후 같은 계약으로 확장한다.
- **FR-004-02** 지원자 개인 자료는 로컬에 유지하고 클라우드 공급자에게 보낼 정보의 범위를 고지한다. 키를 렌더러 번들·로그·DB 평문에 저장하지 않는다.
- **FR-004-03** 간편 지원 공고의 상세 JD와 검증 가능한 경험을 토대로 기존 이력서의 강조점을 조정한다. '10% 수정'은 **사실을 유지하면서 적은 범위로 맞춤화**하는 방향일 뿐 글자수 비율 강제가 아니다.
- **FR-004-04** 수정안의 변경점, 사용된 근거 ID, 누락/불확실 항목을 표시한다. 원본 이력서는 바뀌지 않는다.
- **FR-004-05** **작성과 분리된 AI 리뷰 단계**가 JD 적합성, 허위 경험·성과·자격, 지원자 개인/팀 성과 구분을 점검한다. 리뷰는 작성과 분리된 요청·역할·결과로 기록한다.
- **FR-004-06** 리뷰에서 문제를 발견하면 사용자에게 수정 경고를 표시한다. AI 리뷰 결과 자체는 사람의 최종 승인이 아니다.
- **FR-004-07** 연결 오류/네트워크 오류/쿼터 제한/취소/지원되지 않는 모델을 명확히 구분하고 데이터 손실 없이 처리한다.

## 수용 기준
- **AC-004-01** Given Mock Provider, When 지원서 생성하면 Then 모델/프롬프트 버전과 근거가 첨부된 초안이 저장된다.
- **AC-004-02** Given 기존 자료에 없는 프로젝트 수치가 초안에 등장하면 When 독립 리뷰하면 Then 출처 없는 주장 경고가 표시된다.
- **AC-004-03** Given 사용자 입력이 불완전한 경우 When 생성하면 Then 불확실성을 표시하고 허위로 메우지 않는다.
- **AC-004-04** Given Provider 연결 실패, When 재시도하면 Then 오류는 표시되지만 API 키가 노출되거나 기존 초안이 유실되지 않는다.
- **AC-004-05** Given 초안 생성·AI 검토 완료, When 확인하면 Then 검토 결과와 최종 사용자 승인 단계가 별개로 표시된다.
- **AC-004-06** Given Mock Provider와 합성 요청, When 분석·평가·생성·리뷰 서비스가 호출하면 Then 공통 호출·오류 계약을 사용하고 결과는 작업별로 구분된다. 실제 공급자의 작업별 출력 형식은 해당 Spec 승인 시 확정한다.
- **AC-004-07** Given 처리 중 취소 또는 쿼터 제한/지원 불가 모델/불완전 응답, When 작업이 종료되면 Then 각 사유를 구분하고 기존 저장본은 보존하며 실패 결과를 완료본으로 표시하지 않는다.
- **AC-004-08** Given 초안과 완료된 AI 리뷰, When 기록을 조회하면 Then 작성·리뷰 요청과 결과 및 대상 revision이 별도로 식별된다. 원본 마스터 문서는 변경되지 않는다.

## FR/AC 추적
FR-004-01 → AC-004-06 및 M0/M1 연결 검사; FR-004-02 → AC-004-04 및 기밀·전송 범위 보안 검사; FR-004-03/04 → AC-004-01/03/08; FR-004-05/06 → AC-004-02/05/08; FR-004-07 → AC-004-04/07. 실제 공급자의 연결·키 보호·전송 고지 세부 테스트는 M1 착수 전에 확정한다.

## 미확정/비범위
OpenAI API/Gemini API/Ollama의 최초 구현 순서 및 서로 다른 리뷰 모델의 강제 여부(URS OQ-04). Codex는 **개발 에이전트**와 앱이 호출할 **LLM Provider**를 혼동하지 않는다. 외부 사이트 제출은 수행하지 않는다.
