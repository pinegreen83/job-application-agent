# SPEC-008 — 채용공고 대시보드와 검토 상태

- 상태: Draft / M3 / P0
- URS: UR-007, UR-008

## 기능 요구사항
- **FR-008-01** 메일 원문이 아닌 고유 공고 단위의 목록을 보여주고 추천 순서/마감/검토 상태로 정렬·필터한다.
- **FR-008-02** 공고를 클릭하면 상세 JD, 관련 경험 근거, 필수 자격/직무 경험 평가, 선택 분야 연관성과 원본 링크를 한 화면에서 제공한다. 별도 개인 선호 평가는 표시하지 않는다.
- **FR-008-03** 사용자가 미검토·검토 중·보류·관심·지원 준비·제외 등의 상태를 변경하고 메모를 남길 수 있다. 최종 상태 이름은 UX 검토 후 확정.
- **FR-008-04** 중복 메일은 단일 공고에 묶어 최초·최근 발견 및 출처 이력을 확인할 수 있다.
- **FR-008-05** 마감일 미확인/과거 마감/링크 확인 실패는 별도 상태로 표시하고 임의로 추천 완료 처리하지 않는다.
- **FR-008-06** 앱 종료 후 재실행 시 공고와 검토 상태가 유지된다.

## 수용 기준
- **AC-008-01** Given 한 공고가 3통의 메일에 등장, When 대시보드를 열면 Then 단일 공고 및 3개 출처를 표시한다.
- **AC-008-02** Given 적합성 분석 완료, When 공고를 선택하면 Then 필수 자격과 직무 경험 평가, 선택 분야 연관성 및 각각의 출처 근거를 확인할 수 있다.
- **AC-008-03** Given 공고를 보류 표시한 뒤 앱을 재시작하면 Then 같은 상태가 복원된다.
- **AC-008-04** Given 마감일을 알 수 없는 공고, When 정렬하면 Then '마감 미확인'임이 유지된다.
