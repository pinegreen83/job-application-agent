# SPEC-010 — 지원 완료 기록, PDF 보관, 전형 추적과 아침 알림

- 상태: Draft / M6 / P1
- URS: UR-014, UR-015, UR-016; NFR-001, NFR-005

## 기능 요구사항
- **FR-010-01** 사용자가 외부 플랫폼에서 직접 제출한 뒤 지원 완료를 명시적으로 기록하고 해당 공고와 연결한다.
- **FR-010-02** 실제 제출된 지원서를 PDF로 로컬에 보관한다. 앱에서 작성한 초안 PDF 출력 및 채용 사이트에서 받은 실제 제출본의 로컬 가져오기를 지원 후보로 구분한다.
- **FR-010-03** 기록에는 제출 날짜, 사용한 자료 버전/첨부파일, 지원 링크, 제출 증빙 여부를 보존한다.
- **FR-010-04** 사용자가 서류/시험/면접/최종 결과 등의 전형 상태를 수동 갱신하고 변경 이력을 확인할 수 있다.
- **FR-010-05** 매일 아침 진행 중 지원 건에 대한 확인 알림을 제공한다. 앱이 실행 중일 때 OS 알림을 사용하고, 실행되지 않거나 권한이 없는 상황은 명시하며 다음 실행에서 미확인 건을 안내하는 방안을 포함한다.
- **FR-010-06** 백업·PC 간 동기화는 초기 범위에서 제외한다.

## 수용 기준
- **AC-010-01** Given 지원 링크만 열어본 상태, When 앱에 돌아오면 Then 지원 완료가 자동 기록되지 않는다.
- **AC-010-02** Given 사용자가 제출 완료를 명시적으로 표시하고 실제 제출본 PDF를 연결, When 내역을 열면 Then 지원 건·PDF·제출 날짜가 연결된다.
- **AC-010-03** Given 상태를 면접 단계로 변경, When 앱 재시작하면 Then 최신 상태와 변경 이력이 유지된다.
- **AC-010-04** Given 아침 알림 시간이 되었고 앱에 알림 권한이 있을 때, When 알림 서비스가 실행되면 Then 확인할 진행 건을 알려준다.
- **AC-010-05** Given 예약 시각에 앱이 종료되었던 경우, When 앱을 다시 실행하면 Then 미확인 지원 건을 볼 수 있다. 종료 상태에서 OS 알림을 보장하지 않는다.
- **AC-010-06** Given 제출 PDF를 확인하면 Then 원본 초안과 실제 제출본 여부가 구분된다.

## 미확정
앱 상주/로그인 자동 시작, OS 알림 시간·권한·방식, macOS 배포 조건(URS OQ-05, OQ-06).
