# SPEC-005 — Human Review와 직접 제출용 자료 패키지

- 상태: Draft / M5 / P1
- URS: UR-012, UR-013, UR-014; NFR-009

## 기능 요구사항
- **FR-005-01** 사용자는 원본 JD, 검색 근거, 생성 초안, Diff, AI 리뷰 지적 사항을 비교할 수 있다.
- **FR-005-02** 사용자는 수정·반려·승인을 선택할 수 있다. 승인한 최종본의 버전/해시를 기록한다.
- **FR-005-03** 승인 후 수정하거나 자료를 교체하면 승인 상태를 무효화하고 재검토를 요구한다.
- **FR-005-04** 최종 승인 화면에서 지원 페이지 링크, 확정 이력서, 포트폴리오 첨부 목록, 기업별 문항의 복사 가능한 답변을 깔끔히 제공한다.
- **FR-005-05** 시스템은 제출용 자료를 복사·내보내기 할 수 있어야 한다. 사용자는 시스템 바깥의 사이트에서 직접 지원 버튼을 누른다.
- **FR-005-06** 링크를 열거나 파일을 내보냈다고 지원 완료로 표시하지 않는다. 실제 제출 여부는 사용자 확인을 요구한다.
- **FR-005-07** 지원서 PDF의 최종 보관과 지원 기록 연결은 SPEC-010에서 담당한다.

## 수용 기준
- **AC-005-01** Given 리뷰 대상 초안, When 사용자가 Diff/근거를 확인하면 Then 변경 이유와 사용된 경험을 찾아볼 수 있다.
- **AC-005-02** Given 승인한 초안, When 본문이 수정되면 Then 재승인이 필요하다.
- **AC-005-03** Given 승인된 간편 지원, When 자료 준비 화면을 열면 Then 링크·이력서·첨부 목록을 확인/내보낼 수 있다.
- **AC-005-04** Given 자체 문항 답변, When 자료 준비 화면을 열면 Then 질문별 텍스트를 구별해 복사할 수 있다.
- **AC-005-05** Given 사용자가 지원 링크를 열기만 한 상태, When 관리 화면으로 돌아오면 Then 자동으로 지원 완료 상태가 되지 않는다.
- **AC-005-06** Given 앱 실행, When 어떤 지원 흐름을 수행하더라도 Then 채용 사이트 로그인/제출 버튼의 자동 클릭이 발생하지 않는다.
- **AC-005-07** Given 승인된 자료 패키지, When 이력서·포트폴리오 첨부자료를 교체하면 Then 기존 승인 해시를 현재 패키지의 승인으로 사용하지 않고 재승인을 요구한다.

## 중요한 변경
이전 버전의 자동 제출 어댑터, 제출 성공 응답 자동 판정 요구는 **폐기**. 'submit'은 사용자가 직접 수행하며 이 Spec은 'submission materials handoff'만 포함한다.
