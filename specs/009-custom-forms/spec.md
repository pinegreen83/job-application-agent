# SPEC-009 — 기업 자체 지원 양식 작성 보조

- 상태: Draft / M5 / P1
- URS: UR-009, UR-011, UR-012

## 기능 요구사항
- **FR-009-01** 사용자는 기업 자체 지원서의 질문 및 작성 가이드를 텍스트 복사 또는 화면 이미지로 제공할 수 있다.
- **FR-009-02** 이미지에서 질문과 제한 글자수/조건을 추출·인식하고 불확실한 부분은 사용자 확인 필요로 표시한다.
- **FR-009-03** 문항별 목적과 제약을 고려해 관련 경험·근거를 검색하고 답변 초안을 작성한다.
- **FR-009-04** 글자수 제한, 금지 정보, 확인되지 않은 경력/성과, 실제 질문 불일치 등을 검사·표시한다.
- **FR-009-05** 문항별 편집/재생성을 지원하며, 최종 답변은 사용자 승인 후 SPEC-005의 자료 준비 화면에 전달한다.
- **FR-009-06** 이미지/텍스트의 개인 민감 정보가 공개 로그/저장소에 들어가지 않도록 로컬에서 관리한다.

## 수용 기준
- **AC-009-01** Given 질문 3개와 각기 다른 글자수 제한, When 텍스트 입력하면 Then 3개의 별도 작성 항목 및 제한이 나타난다.
- **AC-009-02** Given 이미지 속 일부 글자가 불명확, When 인식하면 Then 모르는 부분을 임의 확정하지 않고 확인 필요로 표시한다.
- **AC-009-03** Given 관련 경력이 없는 문항, When 초안을 생성하면 Then 허위 경험을 구성하지 않고 부족한 근거를 알린다.
- **AC-009-04** Given 사용자가 답변을 수정한 뒤 승인, When 지원 자료 화면에 가면 Then 최종 승인 버전이 문항별 복사 대상으로 표시된다.
- **AC-009-05** Given 문항별 글자수 제한과 이를 초과한 답변, When 검사하면 Then 해당 문항과 제한 초과를 표시한다. 공백·줄바꿈·문자/바이트 계산 방식은 지원할 양식에 맞춰 착수 전에 확정한다.
- **AC-009-06** Given 금지 정보 또는 확인되지 않은 성과가 포함된 고정 초안, When 검사하면 Then 문제 문구와 근거 부족/금지 사유를 표시하고 자동으로 승인하지 않는다.
- **AC-009-07** Given 질문과 무관한 내용이 포함된 고정 초안, When 검토하면 Then 질문 불일치 경고를 표시한다. 실제 모델의 판정 품질은 별도 AI 평가 세트로 검증한다.

## 미확정
첫 출시 이미지 파서/OCR/비전 모델 방식 및 허용 오차, 이미지 업로드 최대 크기(URS OQ-03).
