# SPEC-007 — 개인화 적합성 분석과 공고 우선순위

- 상태: Draft / M2 / P0
- URS: UR-006, UR-007; NFR-009

## 기능 요구사항
- **FR-007-01** 각 공고에 대해 (A) 지원 가능 여부(필수 자격), (B) JD-경험 연관성을 별도 항목으로 분석한다. 정렬을 위한 선택 분야-JD 연관성은 개인 경험 평가와 구분해 기록한다. 별도 개인 선호 입력·평가는 제외한다.
- **FR-007-02** 각 항목에 확인된 근거(원본 JD/프로필 Episode)와 모름/충돌/미충족 사유를 기록한다.
- **FR-007-03** 기본 목록은 사용자가 선택한 분야와 JD의 연관성이 높은 공고를 먼저 표시하고 판단 근거를 제공한다. 필수 자격과 개인 경험 결과는 별도로 표시하며 기본 정렬의 분야 연관성과 혼합하지 않는다. 마감·검토 상태별 정렬·필터는 기본 정렬과 구분한다.
- **FR-007-04** 분야 선택 방식, 연관성 점수/등급, 동점·분야 미선택·미분석 결과 처리와 필수 자격 미충족 공고의 위치는 구현 전 확정한다(URS OQ-02, OQ-08). 미정 규칙을 구현자가 임의로 정하지 않는다.
- **FR-007-05** 필수조건 미충족과 확인되지 않은 조건을 혼동하지 않는다. 확정 근거가 없는 긍정 평가를 하지 않는다.
- **FR-007-06** 선택 분야와 경험이 갱신된 경우 언제/어떤 분야·프로필 버전으로 평가했는지 식별할 수 있어야 한다. 자동 재평가 정책은 OQ-07에서 정한다.

## 수용 기준
- **AC-007-01** Given 신입 공고와 경력 3년 필수 공고, When 지원 가능성을 분석하면 Then 명시된 경력 조건과 프로필 근거를 구분해 표시한다.
- **AC-007-02** Given 선택 분야와 연관성은 높지만 개인 경험 근거가 부족한 공고, When 평가하면 Then 분야 연관성과 경험 근거 부족이 구분되며 분야 연관성을 자격 충족으로 표시하지 않는다.
- **AC-007-03** Given 지원 조건 누락된 공고, When 평가하면 Then '조건 확인 필요'이지 임의 합격 판정이 아니다.
- **AC-007-04** Given 선택 분야가 게임 클라이언트이고 고정 평가 결과에서 A의 분야 연관성이 B보다 높은 두 공고(동점·실패·필수조건 미충족 예외 없음), When 기본 정렬하면 Then A가 B보다 먼저 표시되고 각 판정 근거를 확인할 수 있다.
- **AC-007-05** Given 프로필의 '금지' 사실, When 평가하면 Then 연관성을 높이는 근거로 활용하지 않는다.
- **AC-007-06** Given 분야 또는 프로필 버전을 변경한 이력, When 이전 평가를 조회하면 Then 평가 당시 분야·프로필 버전·시각을 식별할 수 있다.

## 착수 전 확정할 수용 사례
OQ-02/OQ-08 결정 후 동점, 분야 미선택, 분석 실패, 필수 자격 미충족 공고의 기대 순서를 고정 데이터로 명시한다. 현재 AC는 해당 미정 규칙의 승인을 대체하지 않는다.

## 범위 밖
합격 확률 보장, 숨겨진 기업 내부 채용 기준 예측, 별도 개인 선호 입력·평가.
