# SPEC-003 — 개인 문서 등록과 근거 검색

- 상태: Draft / M2 / P0
- URS: UR-005, UR-006, UR-010, UR-011; NFR-001, NFR-009

## 기능 요구사항
- **FR-003-01** 사용자가 마스터 이력서·자기소개서·프로젝트 경험 자료를 등록, 교체, 삭제하고 문서 버전을 관리한다.
- **FR-003-02** 원문에 있는 실제 사실/회상/불확실/사용 금지 및 개인 역할/팀 성과의 구분을 보존한다. 지원 자료를 통째로 '모든 내용 확정 사실'로 취급하지 않는다.
- **FR-003-03** 문서를 로컬에서 파싱·청크화하고 문서 ID, 버전, Episode/근거 ID, 출처 위치를 연결한다.
- **FR-003-04** JD의 실제 담당 업무와 요건에 대응하는 개인 경험을 검색해 출처와 함께 반환한다.
- **FR-003-05** 관련 근거가 없는 경우 '근거 없음'을 반환하며, 금지된 경험을 추천·생성의 긍정 근거로 사용하지 않는다.
- **FR-003-06** 문서가 변경되면 이전 분석이 참조한 버전을 식별할 수 있고, 새로운 분석에는 사용자가 선택한 유효 버전만 검색된다.
- **FR-003-07** 모든 원본 및 검색 인덱스는 사용자 로컬 저장소에 보관된다. 외부 모델에는 선택된 최소 근거만 명시적으로 전송할 수 있다.

## 수용 기준
- **AC-003-01** Given 가상 문서에 두 프로젝트의 서로 다른 책임이 적혀 있으면 When 직무 검색을 수행할 때 Then 관련 사실과 정확한 출처가 반환된다.
- **AC-003-02** Given '사용 금지' 표시가 있는 경험, When 검색·생성 근거를 준비하면 Then 긍정 근거에서 제외된다.
- **AC-003-03** Given 개인이 하지 않은 팀 성과, When 검색하면 Then 개인 담당 업무로 잘못 변환하지 않는다.
- **AC-003-04** Given 문서 버전 변경/삭제, When 새 검색을 수행하면 Then 변경/삭제된 내용이 새 사실로 무단 재사용되지 않는다.
- **AC-003-05** Given 문서에 없는 자격증, When 확인하면 Then 없거나 미확인이라고 표시한다.

## 기술 검증 메모
SQLite FTS5는 초기 검색 후보(ADR-006). PDF/DOCX 입력 품질, 이미지 파서, 임베딩/하이브리드 검색은 정확도·범위 평가 후 결정한다. 사용자가 제공한 실제 마스터 문서는 **개인 검증용**으로만 활용하며 공개 Fixture에 복사하지 않는다.
