# PRD — Job Application Agent

- 버전: 0.2.1 (2026-11-18)
- 상태: 최초 통합 프로토타입 범위 확정 / 상세 Spec 검토 중
- 제품: 개인화된 채용공고 분석·지원 준비·진행 관리용 로컬 데스크톱 앱
- 원천 요구사항: [URS](./URS.md)

## 문제와 가치
매일 반복 수신되는 추천 채용 메일에는 공고가 다수 포함되고, 중복 공고도 있다. 사용자가 JD를 일일이 확인해 자기 경험과 비교하느라 검토할 공고가 쌓인다. **이 시스템의 일차 목표는 공고를 정리하고 검토 우선순위를 제시하는 것**이다. 지원서 생성은 선별한 공고에 대해 후속 과정을 돕는 기능이다.

## 핵심 시나리오
1. **수집:** 사용자가 선택한 이메일을 전달한다. 한 메일에서 여러 공고가 분리되고 같은 공고가 중복 통합된다.
2. **선별:** 공고별 링크의 JD를 확인해 필수 자격과 개인 경험 연관성을 구분해 평가한다. 기본 목록은 사용자가 선택한 분야와 JD의 연관성이 높은 공고를 우선 표시하고, 근거와 불확실성을 보여준다. 별도 개인 선호 입력·평가는 제공하지 않는다.
3. **관리:** 사용자가 상세 공고를 열고 검토·보류·지원 준비 상태를 선택한다.
4. **지원 준비 A — 간편 지원:** 이력서/포트폴리오를 기업 JD에 맞게 조정하고 독립된 AI 검토 단계를 거쳐 사용자에게 제시한다.
5. **지원 준비 B — 자체 양식:** 사용자가 제공한 문항 텍스트·스크린샷을 바탕으로 항목별 답변을 작성·검토한다.
6. **사용자 직접 제출:** 마지막 화면에서 공고 지원 링크·승인 문서·포트폴리오·복사용 답변을 제공한다. **앱은 제출하지 않는다.**
7. **지원 이후:** 사용자가 실제 제출 완료를 기록하고 최종 제출본 PDF를 보관한다. 이후 전형 상태를 갱신하고 아침 알림을 받는다.

## 최초 릴리스 — 통합 프로토타입
다음 세 영역을 모두 포함한다. 구분은 내부 구현 순서이며 일부 영역만으로 최초 릴리스를 완료하지 않는다.
- **공고 분석·탐색:** 메일 첨부/공고 분리/중복 처리/상세 JD 분석/개인 자료 등록/근거 평가/선택 분야 중심 정렬/검토 상태/로컬 저장.
- **지원 준비:** 간편 지원 수정·독립 AI 리뷰, 자체 양식 문항 지원, Human Review, 직접 제출용 자료·링크 제공.
- **매니지먼트:** 사용자 제출 완료 기록, 실제 제출본 PDF 보관, 전형 추적, 아침 알림.
- **배포:** Windows + macOS 설치본과 신규 버전 안내. 중간 마일스톤 설치본은 검증용이며 최초 통합 릴리스와 구분한다.

Provider 연결은 분석·평가·생성이 공유하는 초기 기반으로 분리한다. Mock 계약을 먼저 검증하고 최초 실제 Provider를 연결한다. 공급자 선정과 호출 세부는 구현 전 확정하며 유료 호출은 임의로 수행하지 않는다.

## 사용자에게 보여야 하는 정보
### 공고 목록
고유 공고 식별, 회사, 직무, 경력/근무 조건, 마감 정보(불명 시 미확인), 적합성 요약, 검토 상태, 마지막으로 발견된 메일 수/날짜, 정렬 근거.

### 공고 상세
원문 JD와 출처 링크, 필수/우대 요건, 사용자 프로필과 연결된 경험 근거, 부족하거나 불확실한 요건, 지원 방식, 지원 준비 시작 버튼.

### 지원 준비/검토
원본 자료 대비 변경 사항, 사용된 경험 ID와 출처, AI 초안과 **독립 리뷰 결과**, 사용자 수동 수정, 승인/반려, 직접 제출을 위한 자료 묶음.

### 지원 관리
제출 여부와 사용자 확인 시각, 제출 링크 및 자료 버전, 실제 제출본 PDF, 전형 진행 단계, 다음 확인 필요 항목, 아침 알림 이력.

## 제품 정책
- 최종 제출과 제출 완료 확인은 사용자 책임. 앱 내 '지원 완료'는 사용자가 직접 기록한 상태와 증빙 여부를 구분한다.
- 공고나 모델의 추론에서 알 수 없는 사실은 모른다고 표시한다.
- 최종 지원서 본문에 개인 프로필의 불확실하거나 사용 금지 상태의 경험을 사실처럼 기재하지 않는다.
- 사용자 PC에 데이터 영구 저장. 외부 AI 공급자 전송은 별도 고지 및 사용자의 설정에 따른다.
- 네트워크/모델 실패 시 기존 데이터·상태 유지.

## 범위 제외
자동 제출/로그인/브라우저 조작, 채용 플랫폼 결과 자동 크롤링, 클라우드 영구 사용자 데이터 저장, 최초 버전의 자동 백업/동기화, 별도 개인 선호 입력·평가. 선택 분야 및 공고의 근무 조건 표시는 유지한다.

## 측정할 지표 (목표값은 데이터 확보 뒤 합의)
- 메일당 고유 공고 추출율, 중복/오병합 발생률
- JD 핵심 필드 추출 정확도 및 확인 필요 비율
- 사용자 검토 시간, 누락/쌓인 공고 수 변화
- 상위 추천 공고의 사용자 채택률, 평가 근거 만족도
- 근거 없는 경험·수치 생성 건수, 리뷰 수정량
- CI/빌드 통과, OS별 설치/기능 스모크 테스트 결과
