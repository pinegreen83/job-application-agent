# URS — 채용공고 분석 및 지원 관리 시스템

- 버전: 0.2.1 (2026-11-18)
- 상태: **최초 통합 프로토타입 범위·기본 정렬·개인 선호 제외 확정 / 상세 Spec 승인 전**
- 기준: 사용자가 직접 설명한 문제·목표·업무 흐름. 기술 구현 방법은 이 문서에서 확정하지 않음.

## 1. 문제 정의 (PS-001)
게임잡·잡코리아 등 채용 플랫폼의 추천 메일이 **하루 약 2통** 오고, 한 통에 많으면 십여 개의 공고가 들어 있다. 같은 공고가 다른 메일에서 반복되기도 한다. 각 메일과 링크를 일일이 열어 JD를 읽고 자신의 경험·지원 방향과 비교해야 하므로 검토 부담이 커지고 미확인 공고가 누적된다.

### 사용자 목표
- 다수의 메일에서 **개별 채용공고를 빠뜨리지 않고 추출·중복 통합**한다.
- 상세 JD와 실제 개인 경험을 연결하여 **검토 우선순위를 결정할 수 있게** 한다.
- 지원할 공고를 선택했을 때 **작성 보조 → AI 검토 → 사용자 최종 승인 → 직접 제출**이 매끄럽게 연결된다.
- 제출한 최종본과 기업별 전형 진행 상태를 관리하고 **아침 확인 알림**을 받는다.

**성공의 핵심:** '지원서 자동 생성'보다 먼저 '누적 공고 검토 부담 감소 및 지원 기회 누락 감소'를 해결한다.

## 2. 사용자 및 업무 범위
- 주요 사용자: 개인 취업 준비생. 개인화 기준을 자신의 이력서·자기소개서·경험 정리 문서로 제공한다.
- 메일 수집: 사용자가 채용 알림 메일을 직접 시스템에 전달하는 흐름을 우선한다. 임의의 전체 수신함 접근은 요구하지 않는다.
- 지원 사이트: 지원자가 외부 채용 사이트에 **직접 제출**한다. 시스템은 링크와 최종 자료를 준비하며 제출 버튼은 누르지 않는다.
- 실제 제출을 확인한 뒤 사용자가 완료 기록을 남기고 최종 제출본을 보관한다.

## 6. 기술 선택 사항 (URS가 아니라 ADR 소관)
사용자가 학습·실험 목적을 고려해 **Tauri 2 / Rust / React+TypeScript / SQLite(RDBMS)** 방향을 선택했다. 선정 이유와 검증 대상은 `docs/DECISIONS.md`에 기록한다. 'Tauri가 반드시 모든 환경에서 더 빠르다'는 요구사항·확정 사실이 아니다.

## 7. 확정하지 않은 사항 (Open Questions)
- OQ-01: 메일 파일 첨부를 포함한다. 최초 지원 형식(`.eml` 제안), 다중 파일 및 본문 붙여넣기의 제공 범위는 상세 Spec에서 확정한다.
- OQ-02: 선택 분야 연관성 우선은 확정. 분야 선택 UI, 동점/미분석/필수 자격 미충족 공고의 위치와 마감 정렬의 세부 동작은 미정.
- OQ-03: 기업 자체 양식에서 이미지/텍스트 추출의 목표 정확도와 지원 형식.
- OQ-04: 독립 AI 검토가 별도 호출/프롬프트면 충분한지, 다른 모델을 요구하는지.
- OQ-05: 앱 창 닫기/완전 종료/PC 로그인 후 자동 실행 시 알림 동작과 OS 권한.
- OQ-06: Apple Silicon/Intel, Windows CPU 아키텍처별 최초 배포 범위 및 코드 서명.
- OQ-07: 개인 자료의 버전 변경 시 과거 적합성 평가 결과를 재계산할지.
- OQ-08: 평가 결과 형식(3단계 추천/점수/설명)과 검증용 표본 구성.

### 최초 릴리스 범위 — 사용자 확정
메일 첨부·다중 공고 추출·중복 통합·JD 분석·분야 중심 정렬, 개인 자료 등록, 간편 지원 맞춤 수정과 독립 AI 검토, 자체 문항 작성, 사용자 승인 및 직접 제출 보조, 제출본 PDF·전형 관리·아침 알림을 **하나의 통합 프로토타입**에 포함한다. Windows/macOS 지원 및 업데이트 안내도 유지한다.

Core/Application/Management 구분은 개발 순서이며 별도의 최초 출시 범위가 아니다. 내부 마일스톤 검증용 설치본과 최초 통합 프로토타입 릴리스는 구분한다. 전체 범위 확정은 모든 세부 FR/AC의 일괄 승인이나 모든 Provider 동시 지원을 뜻하지 않는다. 상세 결정은 해당 기능 착수 전에 확정한다.

## 8. 범위 제외
- 외부 채용 사이트의 자동 로그인·클릭·제출·CAPTCHA 우회
- 자동 합격/불합격 판정 또는 지원 가능성 보장
- 사용자가 제공하지 않은 경력·자격·성과의 생성
- 클라우드 상의 사용자 영구 데이터 저장 서비스
- 최초 버전의 PC 간 자동 동기화 및 백업
- 최초 릴리스의 별도 개인 선호 입력·평가(근무 형태·지역 등의 선호). 공고 조건 표시와 선택 분야 입력은 유지한다.

## 9. 검증 기준
URS 각 항목은 후속 기능 Spec에서 수용 기준(AC)과 연결한다. 인터뷰에서 확인되지 않은 구현 세부는 제안으로 표시하고, 고객 요구사항인 것처럼 확정하지 않는다.
